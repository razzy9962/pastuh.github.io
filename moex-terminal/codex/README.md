# MOEX Terminal

Русскоязычный аналитический терминал для Московской биржи. Next.js App Router, PostgreSQL / Drizzle, TradingView Lightweight Charts. Рыночные данные приходят из API Т-Инвест; сделки совершаются только внутри виртуального счёта — реальные заявки на биржу не отправляются.

## Интерфейс

Оформление повторяет рабочий стол TradingView (тёмная тема): верхняя панель с поиском и уведомлениями, панель графика (символ, интервалы 1м–1Н, тип графика, SMC Pro, виртуальный счёт, магнит, блокировка и видимость рисунков), левый рельс инструментов рисования, правый рельс панелей, панель «Список наблюдения» с котировкой выбранного инструмента, нижняя панель «Обзор / Теханализ / Торговля» и статусная строка. Тема вынесена в `src/app/theme-tradingview.css`; цвета графика заданы в `src/components/trading-chart.tsx`, палитра зон — в `src/lib/smc.ts`.

## Возможности

Единственный индикатор графика — SMC Pro: встроенные SMA/EMA/полосы Боллинджера/RSI и редактор Pine-формул удалены, всё «лишнее» убрано.

- Свечи, линия и область; масштабирование, прокрутка, перекрестие, логарифмическая шкала и экспорт PNG.
- Таймфреймы 1м, 5м, 15м, 1ч, 4ч, 1Д и 1Н.
- Каталог: 254 акции Московской биржи (весь рынок TQBR) с делением на 1-й, 2-й и 3-й эшелоны, плюс индексы IMOEX/RTSI/RGBI и валюта CNYRUB_TOM — всего 258 инструментов. Поиск с фильтром по эшелону, обзор рынка и скринер с колонкой «Эшелон», CSV-экспорт.
- SMC Pro: Order Blocks по методу LuxAlgo, структура BOS/CHoCH, FVG, EQH/EQL, Premium/Discount, POC и Value Area, ключевые уровни PDH/PDL, PWH/PWL, свинги 1ч и 4ч, EMA со старших таймфреймов, A+ зоны по конфлюенсу и метки BUY / SELL.
- Горизонтальные уровни, линии тренда, измерения, блокировка и скрытие рисунков.
- Виртуальный счёт 10 000 000 ₽: рыночные заявки в лоты или на сумму, лонг и шорт с плечом до 1:3, тейк-профит и стоп-лосс, таблица позиций, история сделок и статистика.
- История сделок: закрытые сделки пишутся в `localStorage` (ключ `moex-account`) вместе с балансом и открытыми позициями — до 500 последних, переживают перезагрузку страницы и перезапуск сервиса на Render. По умолчанию в окне показываются все сохранённые сделки; внизу окна есть «Экспорт истории CSV». При сбросе счёта история очищается — перед сбросом сделайте экспорт.
- Интерфейс в тёмной теме TradingView, адаптация под узкие экраны.
- Автосохранение настроек SMC и рисунков: в PostgreSQL, если задан `DATABASE_URL`, иначе — в браузере (localStorage). Анонимное рабочее пространство изолировано HttpOnly-cookie.
- Хостинг на бесплатном тарифе Render: `render.yaml` в корне `codex/` (Blueprint), лимиты heap выставлены под 512 МБ, health check `/api/health` отдаёт потребление памяти.

## Запуск

1. Установить зависимости: `npm install`.
2. Переменные окружения не обязательны: серверный токен Т-Инвест уже прописан по умолчанию (`src/lib/market-server.ts`), а значение из `.env.local` / `TINKOFF_TOKEN` его перекрывает. `DATABASE_URL` нужен только для сохранения настроек на сервере. Примеры — `.env.example`. Токен используется только на сервере и в браузер не попадает.
3. При работающем PostgreSQL применить схему: `npx drizzle-kit push`.
4. Разработка: `npm run dev`. Продакшен: `npm run build`, затем штатный запуск приложения.

`/api/health` проверяет доступность PostgreSQL. Рабочего PostgreSQL в локальной среде может не быть — терминал в этом случае работает с локальной копией настроек в браузере.

Запросы к Т-Инвест повторяются при ответах 404/429/5xx шлюза провайдера (до трёх попыток), поэтому кратковременные сбои не переводят график в резервный источник.

Глубина истории: 1м — 900 баров, 5м/15м — 1000, 1ч — 1200 баров, 4ч (агрегируется из часовых, отдельного интервала у провайдера нет) — 1000, 1д — 1000 баров (около трёх лет), 1Н — 284 бара с 2021 года. Недельный интервал провайдер отдаёт максимум за ~2000 дней — дальше свечей нет.

Котировки запрашиваются напрямую по идентификаторам `TICKER_TQBR` / `TICKER_CETS`, а индексы — по `uid` из сервиса `Indicatives` (по тикеру `IMOEX` свечи не отдаются): каталог акций провайдера весит ~3 МБ и на медленном канале не успевал загружаться (из-за этого раньше все котировки незаметно заменялись демонстрационными). Сейчас живые данные приходят по всем 258 инструментам. Причина любого отката видна в логах сервиса строкой `[tinvest]` или `[quotes]`.

## Проверки

`npm test` — 21 тест: OHLCV демо-свечей, каталог и эшелоны, настройки по умолчанию, Order Blocks по методу LuxAlgo, FVG, уровни, отсутствие lookahead у EMA старших ТФ, валидация настроек SMC, а также брокер виртуального счёта: маржа, комиссия, лонг/шорт, частичное закрытие, тейк-профит и стоп-лосс, санитизация сохранённого счёта (тесты читают TypeScript напрямую через `tsx`, Node.js 20+). При работающем приложении: `node tests/api-smoke.mjs` — данные рынка, валидация и сохранение рабочего пространства. Для другого адреса задайте `API_BASE_URL`.

## Бесплатный Render

Код подготовлен под ограничения Free-тарифа: RSS 100–150 МБ при лимите 512 МБ, ответы API сжаты gzip и отдают `ETag`/`304`, в скрытой вкладке опрос приостанавливается, `/api/health` не отвечает 503 из-за базы, `robots.txt` закрыт от краулеров, кеш свечей ограничен 40 наборами, а котировки запрашиваются пакетами. Таблица «ограничение → решение» и разбор типичных ошибок деплоя — в `RENDER.md`.

Проверка типов и сборки: `npx next typegen`, `npm exec tsc -- --noEmit --pretty false`, `npm run build`.

## Источники данных и безопасность

Основной источник — официальный REST API Т-Инвест. Рыночные данные обновляются раз в 30 секунд, серверный кеш — 25 секунд. Токен никогда не отправляется в браузер.

API Т-Банка использует цепочку Russian Trusted CA. Публичный корневой сертификат в `certs/russian-trusted-root-ca.pem` скачан по HTTPS из официального источника: https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt. SHA-256: `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`. Проверка сертификата и имени хоста включена. Дополнительное доверие применяется только к запросам Т-Инвест, а не глобально. Публичный сертификат не является секретом.

Резерв — MOEX ISS с задержкой до 15 минут. При недоступности обоих источников выводятся явно обозначенные демонстрационные данные; они не выдаются за реальные котировки. Для приостановленных валютных инструментов возможен только справочный / демонстрационный график.

## SMC Pro (порт Pine Script v6)

Индикатор `SMC Pro [improved + LuxAlgo OB]` портирован с Pine Script v6 на TypeScript:

- `src/lib/smc.ts` — вся математика (ATR, пивоты, ноги LuxAlgo, парсинг high/low с фильтром волатильности, блоки, FVG, EQH/EQL, профиль объёма, конфлюенс, статистика отработки, EMA старших ТФ через агрегацию свечей с лагом в один бар старшего ТФ), схема настроек и её валидация;
- `src/components/smc-primitive.ts` — примитив lightweight-charts: зоны, линии уровней, подписи BOS/CHoCH и метки на ценовой шкале;
- `src/components/smc-panel.tsx` — панель настроек и дашборд (кнопка «SMC Pro» на панели инструментов графика).

Логика Order Blocks повторяет Smart Money Concepts [LuxAlgo] (CC BY-NC-SA 4.0). Расчёт детерминирован, использует только закрытые бары и не репейнтит. Настройки SMC входят в рабочее пространство (`WorkspaceSettings.smc`), сохраняются в PostgreSQL и проходят серверную валидацию, как и остальные поля.

## Виртуальный счёт

- `src/lib/broker.ts` — арифметика счёта: маржа (`notional / 3` + комиссия), комиссия 0,05 % за сторону, реализованный и нереализованный результат, частичное закрытие, срабатывание тейк-профита и стоп-лосса по свече, эквити и свободные средства, `sanitizeAccount` для данных из `localStorage`.
- `src/components/trading-panel.tsx` — тикет заявки, таблица позиций, компактная строка счёта и модальное окно со вкладками «Позиции / История / Статистика».

Счёт пополняется до 10 000 000 ₽ кнопкой «Сбросить счёт» в окне виртуального счёта. Реальные заявки не отправляются.

## Изменение набора индикаторов

Расчёты находятся в `src/lib/smc.ts`, отрисовка — в `src/components/smc-primitive.ts` и `src/components/trading-chart.tsx`. Исходный код Pine Script или Python не исполняется через eval: его необходимо адаптировать к функциям расчёта временного ряда и добавить в конвейер SMC.

Графики используют [TradingView Lightweight Charts](https://www.tradingview.com/lightweight-charts/), Apache 2.0. Терминал не является продуктом TradingView или Московской биржи. Данные и расчётные оценки не являются инвестиционной рекомендацией.
