# Деплой на Render (Web Service, бесплатный тариф)

Render подхватил репозиторий как Python — это из-за `requirements.txt` в корне.
Для терминала нужен **Node**. Значения для формы «New → Web Service»:

| Поле | Значение |
| --- | --- |
| Source Code | `razzy9962/invest` (ветка `main`) |
| Language | **Node** |
| Branch | `main` |
| Region | **Frankfurt (EU Central)** — ближе к MOEX, меньше задержка |
| Root Directory | `moex-terminal/codex` |
| Build Command | `npm ci --no-audit --no-fund && npm run build` |
| Start Command | `npm run start` |
| Instance Type | Free |

Если в корне репозитория лежит не папка `moex-terminal`, а сразу `codex` —
Root Directory пишите `codex`.

## Переменные окружения (Environment)

Обязательных нет: токен Т-Инвест уже вшит в код и в `render.yaml`.

Рекомендуется добавить, чтобы уложиться в 512 МБ:

```
NODE_VERSION=20.18.1
NODE_OPTIONS=--max-old-space-size=420
NEXT_TELEMETRY_DISABLED=1
```

`DATABASE_URL` не нужен — без него настройки хранятся в браузере.

## Альтернатива: Blueprint

Если в репозитории есть `render.yaml` (он лежит в `codex/`), можно сделать
**New → Blueprint** и выбрать репозиторий: сервис создастся сам, все команды и
переменные возьмутся из файла.

## После деплоя

- Приложение: `https://<имя>.onrender.com`
- Проверка живости и памяти: `https://<имя>.onrender.com/api/health`
  (`memoryMb.rss` должен быть в районе 110–150 МБ)
- Первый запрос после 15 минут простоя грузится 30–50 секунд — это сон
  бесплатного тарифа, не ошибка.

## Что уже оптимизировано под бесплатный тариф

| Ограничение Render Free | Что сделано в коде |
| --- | --- |
| 512 МБ RAM, риск OOM | `NODE_OPTIONS=--max-old-space-size=420` в `render.yaml`; кеш свечей ограничен 40 наборами (LRU); котировки и каталог кешируются в процессе, без внешних сервисов. Фактическое RSS — 100–150 МБ. |
| 5 ГБ исходящего трафика в месяц (общие на рабочее пространство, при исчерпании сервисы **выключаются до конца месяца**) | JSON-ответы API сжимаются gzip вручную (`src/lib/http.ts`): котировки 15 КБ → 5 КБ, свечи 19 КБ → 6 КБ. Поддержаны `ETag` и `304 Not Modified`, у каталога `Cache-Control: max-age=3600`. |
| Сон через 15 минут без входящего трафика | Для сервиса это нормально; чтобы страница не «висела» при холодном старте, первый рендер идёт на демо-данных, живые подставляются после ответа API. |
| Опрос данных каждые 30 секунд | В скрытой вкладке (`document.hidden`) опрос приостанавливается и сразу возобновляется при возврате — трафик не тратится впустую. |
| «Подозрительно высокий исходящий трафик к внешним API» (может привести к приостановке сервиса) | Запросы к Т-Инвест кешируются: котировки 30 с, свечи 30 с, список инструментов 4 ч, каталог символов отдаётся из своего кода. За один цикл обновления — 3 пакетных запроса на 60 бумаг вместо одного на 254. |
| Health check | `/api/health` **всегда отвечает 200**; состояние базы отдаётся полем `database`. Недоступная БД больше не вызывает циклические перезапуски сервиса. |
| Краулеры будят инстанс и едят трафик | `src/app/robots.ts` отдаёт `Disallow: /` для всех агентов. |
| Эфемерный диск, сон стирает файлы | Ничего важного на диск не пишется: настройки и виртуальный счёт живут в `localStorage` браузера. |
| Нет Edge caching на Free | Свои заголовки кеша + gzip дают тот же эффект на уровне браузера. |
| Долгая сборка съедает build minutes | Сборка ~7–15 с (Turbopack), `npm ci` с `--no-audit --no-fund`; лишних зависимостей нет. |
| Каталог акций Т-Инвест весит ~3 МБ и грузится 20+ секунд — на медленном канале обрывался, и все котировки становились демо | Каталог больше не запрашивается: котировки идут напрямую по `TICKER_TQBR` (пакеты по 60), индексы — из сервиса `Indicatives`, он маленький и кешируется на 12 часов. Таймаут теперь считается от активности (12 с без данных), а не на весь ответ. |
| Непонятно, почему данные демонстрационные | В логах сервиса появились строки `[tinvest] Service/Method: причина` и `[quotes] T-Invest: причина`. В интерфейсе при демо-режиме в уведомлениях есть кнопка «Повторить запрос». |

## Частые причины неудачного деплоя

- **`Exited with status 1` за 10–15 секунд + в логах справка `npm ci`** — неверный Build Command или Root Directory. Должно быть ровно `npm ci --no-audit --no-fund && npm run build` (без `$` и без префикса `codex/`). Root Directory — папка, где лежит `package.json`.
- **Сервис определился как Python** — в корне репозитория есть `requirements.txt`; выберите Language **Node** вручную.
- **Build падает по памяти** — оставьте только `NODE_OPTIONS=--max-old-space-size=420`, не запускайте сборку локально параллельно.
- **`next: not found` при старте** — Start Command должен быть `npm run start`, а Build Command обязан выполнять `npm ci`.
