# 15 стратегий + вшитый сайт — установка за 2 минуты

## Что в папке

| Файл | Зачем |
|---|---|
| `strategies.py` | Движок: 15 стратегий, настоящий CVD по ленте, риск-профили |
| `web_ui.py` | Весь веб-терминал (gzip+base64) прямо в коде — `index.html` на диске больше не нужен |
| `apply_patch.py` | Автопатчер: сам вносит все правки в `investrobot.py` |
| `build_web_ui.py` | Пересобрать `web_ui.py` после обновления фронта |

## Установка

Положи все 4 файла рядом с ботом и запусти:

```bash
python3 apply_patch.py "investrobot (18).py"
```

Увидишь:

```
[i] резервная копия: investrobot (18).py.bak
  [+] фикс f-string (запуск на Python 3.11)
  [+] импорт движка стратегий + вшитого сайта
  [+] каталог STRATS → 15 стратегий
  [+] strategy_side() → новый движок
  [+] честные тейп-поля CVD в cvd_data
  [+] лимиты/кулдаун/цели по каждой стратегии
  [+] отдача сайта из памяти (gzip)
[+] синтаксис в порядке — можно запускать бота
```

Скрипт **идемпотентный** — повторный запуск ничего не сломает. Откат: `cp "investrobot (18).py.bak" "investrobot (18).py"`.

Токены, ключи и настройки не трогаются вообще.

## Список стратегий

### Настоящий CVD (по ленте реальных сделок)
| Ключ | Название | Логика входа |
|---|---|---|
| `cvd_flow` | 💧 Поток CVD | Поглощение/давление дельтой + фильтр «свеча врёт» |
| `cvd_mtf` | 🧬 MTF-дельта | Дельта согласована минимум на 3 из 5 ТФ |
| `cvd_impulse` | ⚡ Импульс дельты | Всплеск дельты (эффективность ≥18%) + RVOL ≥1.3 |

### Дивергенции
| `divergence` | ⚠️ Пивот-дивергенция | Цена делает экстремум, реальный CVD — нет |
| `div_candle` | 🕯 Ложная свеча | Зелёная свеча при отрицательной дельте и наоборот |

### Крупный капитал в ленте
| `big_prints` | 🐋 Крупные принты | Нетто принтов ≥1 млн ₽, свежесть ≤3 мин, доля ≥12% оборота |
| `twap_algo` | ⏲ TWAP / алго | Растут средний чек и частота крупных сделок |
| `minute_press` | ⏱ Минутное давление | Большой нетто-объём при движении ≤0.5% |
| `robot_illiquid` | 🔁 Роботы в неликвиде | Повторяющиеся принты с равным шагом, оборот <3 млрд ₽ |

### Стакан
| `iceberg` | 🧊 Айсберги | Скрытая лимитка восстанавливается после съедания |
| `book_imbal` | 📚 Дисбаланс стакана | Перевес bid/ask + стена в нужную сторону |

### Уровни и цена
| `poc_revert` | 🎯 Возврат к POC | Отклонение 0.8–3 ATR от POC с разворотной дельтой |
| `sr_break` | 🧱 Пробой уровня | Пробой S/R при RVOL ≥1.4 и подтверждении дельтой |
| `vwap_trend` | 📈 VWAP-тренд | Цена над/под VWAP + стек EMA 9/20/50 |
| `index_decouple` | 🧭 Расхождение с IMOEX | Бумага против индекса на своей дельте (спред ≥0.8%) |

Старый ключ `news_whale` сохранён для совместимости.

## Что такое «настоящий CVD» здесь

Ты просил CVD **по реальным сделкам, а не по свечам** — именно так и сделано. Функция `real_cvd(sig)` берёт только тейп-поля:

- `tape_buy_vol` / `tape_sell_vol` — объём агрессора-покупателя и продавца;
- `tape_net_lots` — их разница (это и есть настоящая дельта);
- `tape_cum_delta` — накопленная дельта по ленте;
- `tape_cov_pct` — какую долю свечи реально покрыла лента.

Патч добавляет эти поля в `cvd_data` (шаг 4) — раньше они считались внутри, но наружу не отдавались.

Свечная аппроксимация (`bar_delta`) используется **только** как запасной вариант и помечается флагом `approx=True`. Стратегии с `requires_real_cvd=True` **не входят**, если покрытия ленты не хватает (порог `min_tape_cov` у каждой свой) — то есть на плохих данных бот просто молчит вместо выдумывания сигналов.

## Риск-профили

У каждой стратегии в `STRAT_RISK` свои параметры:

```python
"cvd_mtf": {"tp_mult": 3.0, "sl_mult": 1.2, "max_pos": 4,
            "cooldown": 3600, "min_rr": 2.0,
            "requires_real_cvd": True, "min_tape_cov": 50.0},
```

- `tp_mult` / `sl_mult` — множители ATR для тейка и стопа;
- `max_pos` — лимит одновременных позиций у этого счёта;
- `cooldown` — пауза по тикеру, сек;
- `min_rr` — не входить, если R/R хуже;
- `min_tape_cov` — минимальное покрытие ленты, %.

Меняй прямо в `strategies.py` — перезапуск бота подхватит.

## Общие фильтры (работают для всех)

Перед любым входом проверяется: бумага ликвидна, рынок открыт, спред ≤0.6%, нет дивидендной отсечки на носу, R/R не хуже порога стратегии. Любая ошибка внутри стратегии = «сигнала нет», торговый цикл не падает.

## Обновление сайта

Фронт пересобрал → вшиваешь заново:

```bash
python3 build_web_ui.py ../dist/index.html
```

Бот отдаёт страницу из памяти сразу в gzip (≈142 КБ вместо 462 КБ) — грузится заметно быстрее, и деплой не может «потерять» файл.

## Деплой

```bash
git add strategies.py web_ui.py apply_patch.py build_web_ui.py "investrobot (18).py"
git commit -m "15 стратегий на реальном CVD + вшитый веб-терминал"
git push
```

На Render/хостинге убедись, что `strategies.py` и `web_ui.py` лежат **в той же папке**, что и файл бота.
